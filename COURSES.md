# MUSICA — PAGINA PRINCIPAL

Cursos de historia y teoría musical.

Cada curso de este repo es independiente (su propio README, roadmap y
lecciones en LESSON.md generando su index.html). Esta página es el punto de
entrada: lista todos los cursos, los describe, y linkea a cada uno.

Se genera con `make site` (`tools/build_index.py`) leyendo este mismo archivo
— el html no se edita a mano.
