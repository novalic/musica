# música — catálogo de cursos

Repo de cursos de historia y teoría musical.

Abrí `index.html` (`make open`) para el catálogo lindo, o navegá este README en GitHub.

## Cursos

- [historia_musical](historia_musical/README.md) — historia de la música de cero a experto: desde la música antigua hasta los géneros populares de hoy, incluyendo tradiciones regionales como el flamenco, el tango y el fado.
